1. ภาพรวมระบบ (System Overview) 
flowchart TD
    START([Start]) --> A[ผู้ใช้งานเข้าเว็บ]
    A --> B{มีบัญชีหรือไม่?}
    B -- "ไม่มี" --> C[ลงทะเบียน /register]
    B -- "มี" --> D[เข้าสู่ระบบ /login]
    C --> D
    D --> E{ตรวจสอบ Role}
    E -- "ADMIN" --> F[Admin Dashboard]
    E -- "TENANT" --> G[Tenant Dashboard]
    E -- "MAINTENANCE" --> H[Maintenance Dashboard]
    E -- "EXECUTIVE" --> I[Executive Dashboard]
    F --> END1([End])
    G --> END1
    H --> END1
    I --> END1
2. ระบบ Authentication — Login 
flowchart TD
    START([Start]) --> A[ผู้ใช้กรอก Email + Password]
    A --> B[POST /api/auth/login]
    B --> C{ตรวจสอบข้อมูล}
    C -- "ไม่ถูกต้อง" --> D[แจ้ง Error]
    D --> END1([End])
    C -- "ถูกต้อง" --> E[สร้าง JWT Token]
    E --> F[ส่ง Token + User Data กลับ]
    F --> G[เก็บ Token ใน Zustand Store]
    G --> H[Redirect ตาม Role]
    H --> END2([End])
2. ระบบ Authentication — Register 
flowchart TD
    START([Start]) --> A[ผู้ใช้กรอกข้อมูลลงทะเบียน]
    A --> B[POST /api/auth/register]
    B --> C{Validate ข้อมูล}
    C -- "ไม่ผ่าน" --> D[แจ้ง Error]
    D --> END1([End])
    C -- "ผ่าน" --> E[Hash Password + บันทึก DB]
    E --> F[สร้าง User role: TENANT]
    F --> END2([End])

7. Flow การเรียกเก็บค่าเช่ารายเดือน (Billing Process) 
flowchart TD
    START([Start]) --> A[เริ่มรอบเดือนใหม่]
    A --> B[Admin บันทึกมิเตอร์น้ำ/ไฟ]
    B --> C[ระบบคำนวณหน่วยที่ใช้]
    C --> D[Admin สร้างบิล]
    D --> E[คำนวณ: ค่าเช่า + ค่าน้ำ + ค่าไฟ + ค่าบ่อดักไขมัน]
    E --> F[บิลสถานะ: PENDING]
    F --> G[ผู้เช่าเห็นบิลใน Dashboard]
    G --> H[ผู้เช่าชำระเงิน + อัปโหลดสลิป]
    H --> I[Admin ตรวจสอบหลักฐาน]
    I --> J{ถูกต้อง?}
    J -- "ใช่" --> K[สถานะ: PAID]
    J -- "ไม่" --> L[สถานะ: OVERDUE]
    K --> END1([End])
    L --> END1
8. Flow การแจ้งซ่อม (Maintenance Request Process) 
flowchart TD
    START([Start]) --> A[ผู้เช่าพบปัญหา]
    A --> B[แจ้งซ่อมผ่านระบบ]
    B --> C[กรอกหัวข้อ + รายละเอียด + แนบรูป]
    C --> D[สถานะ: PENDING]
    D --> E[Admin เห็นรายการแจ้งซ่อม]
    E --> F[Admin มอบหมายช่าง]
    F --> G[ช่างได้รับงาน]
    G --> H[ช่างเริ่มดำเนินการ]
    H --> I[สถานะ: IN_PROGRESS]
    I --> J[ช่างซ่อมเสร็จ + อัปโหลดหลักฐาน]
    J --> K[สถานะ: COMPLETED]
    K --> L[ผู้เช่าเห็นผลการซ่อม]
    L --> END1([End])
9. Database Schema Overview 
erDiagram
    User ||--o| Stall : rents
    User ||--o{ Bill : has
    User ||--o{ Contract : has
    User ||--o{ MaintenanceRequest : creates
    Stall ||--o{ MeterReading : records
    Stall ||--o{ Bill : has
    Stall ||--o{ Contract : has
    Stall ||--o{ MaintenanceRequest : has

    User {
        string id PK
        string email
        string password
        string name
        enum role
    }

    Stall {
        string id PK
        string stallNumber
        int foodCourt
        enum status
        float monthlyRent
    }

    Bill {
        string id PK
        float rentAmount
        float waterAmount
        float electricAmount
        float totalAmount
        enum status
    }

    Contract {
        string id PK
        date startDate
        date endDate
        boolean isActive
    }

    MaintenanceRequest {
        string id PK
        string title
        string description
        enum status
    }

    MeterReading {
        string id PK
        date month
        float waterReading
        float electricReading
    }

    Settings {
        string id PK
        string key
        string value
    }
